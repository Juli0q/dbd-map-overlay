How it works

The system captures screenshots of the bottom-left corner of your screen where DBD displays the map name.

It uses OCR (Optical Character Recognition) to read the text and automatically matches it to the correct map.

Make sure DBD is running in windowed or borderless windowed mode for best results.

Requirements
  • Dead by Daylight must be running in windowed or borderless windowed mode
  • The map name area (bottom-left) should be clearly visible
  • Works on both Linux (X11 & Wayland) and Windows
  • Requires screen capture permissions on some systems
